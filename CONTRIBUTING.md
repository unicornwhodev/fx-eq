# Contributing to UWdeVST

Thank you for taking the time to test the plug-in and share useful feedback.

## Feedback and issue reports

Use the repository's **Bug report** or **Feature request** issue form. Before opening an issue, search existing reports and include the plug-in version, Windows version, DAW or Standalone host, reproduction steps and any relevant logs.

## Code contributions

Code contributions, pull requests, patches, modified builds and derivative versions are not solicited or accepted. Please do not submit copyrighted code or assets through an issue.

The repository is publicly viewable under the **UWdeVST Proprietary Public-Source License v1.0**. Viewing and private compilation of strictly unchanged source are permitted by that license; modification and redistribution are not.

## Security reports

Do not publish an exploit or sensitive technical detail in a public issue. Send a concise report to unicornwhodev@gmail.com with the repository name and affected version.
